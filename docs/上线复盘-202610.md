## 关键经验

1. **ICP 备案硬前提**：备案服务码需要一台阿里云内地服务器（包年包月 ≥3 个月）——¥99/年 ECS 一举两得（备案载体 + 网站主机）。
2. **个人备案名称**：避开“博客/空间/论坛/在线/平台/中心”等禁用词，“姓名+个人网站”格式最稳。
3. **管局效率**：山东管局 ICP 从提交到下号 8 天（10-14 提交 → 10-22 下号），快于常见预期。
4. **公安备案入口**：政务服务门户的地区过滤会显示“尚未上线”，**直接走 beian.mps.gov.cn** 用统一认证登录即可；域名注册服务商下拉若无阿里云，选“其他”可过。
5. **安全组易踩坑**：ECS 控制台的规则要加到**实例实际绑定的安全组**（实例详情页可见绑定关系），加错组不生效。
6. **备案号合规**：页脚“底部居中 + 链接 beian.miit.gov.cn”，有 IP 直连和域名两条验证路径，部署完先自查再等核查。
7. **PowerShell 管道陷阱**：git show / curl 的 UTF-8 输出经 PowerShell 管道会双重编码，中文内容一律用 Python subprocess 字节流处理。
